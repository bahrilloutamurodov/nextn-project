# Build Project

Follow these steps to build the project:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Type Checks**:
   ```bash
   npm run typecheck
   ```

3. **Compile Production Build**:
   ```bash
   npm run build
   ```
